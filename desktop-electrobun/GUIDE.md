# DeepSeek Harness Desktop（Electrobun 版）使用指南

给使用者的说明：安装、日常使用、设置项含义、常见故障排查。构建与开发见 [README.md](README.md)。

## 安装

| 平台 | 产物 | 安装方式 |
|---|---|---|
| macOS（Apple Silicon） | `macos-arm64-DeepSeekHarnessDesktopBUN.dmg` | 打开 DMG，把 App 拖进「应用程序」。首次打开如提示无法验证：右键 →「打开」，或 `xattr -cr "/Applications/DeepSeek Harness Desktop BUN.app"` |
| Windows（x64） | `windows-x64-DeepSeekHarnessDesktopBUN-setup.exe` | 双击安装器；可选择安装目录（默认装到当前用户目录，不需要管理员）。Windows 网络下载的 exe 可能触发 SmartScreen →「仍要运行」 |

首次启动会先出现一个小的**启动界面**（显示启动阶段），dsh 服务就绪后主窗口自动出现。
如果这是全新安装，应用会自动准备 `desktop` profile 并安装内置 dsh 运行时——什么都不用装。

## 日常使用

### 窗口

- **关闭窗口** = 最小化到托盘（第一次会有提示通知），dsh 服务继续在后台跑；真正退出请用托盘菜单的「退出」。
- **多 profile 多窗口**：托盘「PROFILE 窗口」子菜单列出所有 profile——已运行的显示端口与运行状态，点「聚焦窗口」切过去，没开的点名字开新窗；运行中的条目里还有「退出（停止实例）」。
- 托盘**左键单击**图标 = 聚焦最后使用的窗口（没有窗口就开主 profile 的窗）。
- 窗口位置与大小会被记住（每个 profile 各自记忆）。

### 托盘菜单

- **运行时版本**：已下载的版本点击即切换（「当前运行」标记 = 正在用的那个）；「内置」是随安装包的版本；「外部 dsh」= 用系统里自己装的 `dsh` CLI；「下载并切换」从 npm/GitHub 拉新版本（下载有进度通知）。
- **dsh 服务地址**：本地 / 远程二选一。选远程前先在设置里加远程地址。
- **重启 dsh 服务**：改了设置或 dsh 卡住时用；**注册 dsh 为系统命令**（只在检测到未注册/冲突时出现）：把 `dsh` 命令链接进 `/usr/local/bin`，终端里直接敲 `dsh` 就能用。
- **退出**：停掉所有 dsh 实例并退出应用（回收所有子进程，不留孤儿）。

### 端口被占用时：兼容 / 高级模式

如果启动时发现目标端口已被另一个 dsh 占用（比如你自己开的终端 dsh），启动界面会问你：

- **兼容模式**：不杀任何进程，直接复用那个外部实例（可以把 `dsh web` 打印的带 token URL 粘进去）。
- **高级模式**：停掉占用的 dsh 进程，由壳自己拉起并注入桌面功能（桌面 chrome、通知、防休眠等只在高级模式生效）。

### 通知

设置 → 桌面通知：总开关、免打扰时段、全屏静默、14 个场景（会话完成、启动受阻、运行时下载……）各自独立开关与音效，可试听。
系统未授权通知时界面会提示；macOS 上如果授权异常，确认应用是**从安装包装的**（开发模式跑的未签名实例拿不到通知授权）。

### 防休眠

设置里「阻止系统休眠」默认开：任一 profile 有会话在跑时，系统不会进入空闲休眠（屏幕照常熄灭）；等审批、等你输入不算「在跑」；会话结束或退出应用立即释放。

### 手机访问

手机和电脑连同一网络后，用手机浏览器打开 dsh 侧栏「远程访问」显示的地址即可。桌面壳在跑的时候会自动把手机访问端口转发到当前聚焦的窗口。

## 设置项速查（设置 → 桌面设置）

| 设置 | 说明 |
|---|---|
| dsh 来源 | 内置（随安装包）/ 外部（系统装的 dsh CLI）；外部版本过旧会有兼容提示 |
| dsh 服务地址 | 本地，或填远程 `http://host:port`（壳直连远程，不再本地拉服务） |
| Profile / Profile 端口 | 多 profile 管理与端口（web=3080、desktop=3081，其余自动分配；lane 错开 3092 起） |
| 迁移 Profile | 全量复制一个 profile 到另一个（目标已存在需确认覆盖） |
| dsh 运行时 | 列出已装版本，可下载 / 切换 / 卸载（卸载进回收站，重启时清理） |
| 代理 | off / system（读系统设置，含凭据）/ manual（手填）；会注入给 dsh 子进程 |
| 下载 | 并发数等下载管理器参数 |

旧版（Tauri 壳）的 `settings.yaml` 会在首次启动时**只读迁移**成新格式，不会被改动或删除——回退旧版本设置不丢。

## 故障排查

1. **启动卡住 / 失败**：启动界面会显示红字原因；日志在 `~/Library/Logs/com.hyperion.dsh-desktop-bun/`（macOS）或 `%LOCALAPPDATA%\DeepSeekHarnessDesktopBUN\`（Windows）。
2. **页面空白**：托盘 →「重启 dsh 服务」；仍不行就「退出」后重新打开（单实例锁不会阻碍重开）。
3. **换端口**：设置 → Profile 端口，改完会重启对应 profile。
4. **终端里没有 `dsh` 命令**：托盘 →「注册 dsh 为系统命令」。
5. **插件起不来 / 模型列表空**：设置 →「依赖状态」看是否需要「重建依赖」（pnpm 大版本不一致时需要）。
6. **完全重置**：退出应用后删 `~/.dsh` 下对应 profile（会丢会话与设置，慎用）。

## 与旧版（Tauri 壳）的差异

- 引擎换成 CEF/V8：macOS 上不再出现「白屏后自动刷新」（旧壳的 JSC 崩溃族）。
- 每个 profile 独立窗口（不再单窗切换 profile）。
- 托盘无文字标题，纯图标；左键点击聚焦窗口。
- 桌宠暂未迁移（维护者决定不做）。
- 应用名 / bundle id：`DeepSeek Harness Desktop BUN`（`com.hyperion.dsh-desktop-bun`）。
